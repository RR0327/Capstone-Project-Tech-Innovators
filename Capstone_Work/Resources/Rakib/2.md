> Intrusion and Non-Intrusion Detection based on

_**Intrusion** vs **Non-Intrusion Detection**_ = CCTV dekhe bolbe “keu restricted area te dhukse kina”.

Eta holo real-world CV + DL project. Ami tomake 0 to deploy porabo, tomake ar kothao jaite hobe na.

# 1. _Project er Core Idea_

- _Intrusion_ = Unauthorized person restricted area te dhukse
- _Non-Intrusion_ = Normal activity, authorized person, kono threat nai

- _Example:_  
  Raat 2 tay factory er store room e 1 jon dhuklo = Intrusion → Alarm  
  Din er bela security guard dhuklo = Non-Intrusion → Ignore

# _2. System er 5 ta Step_

#### _Step 1: Data Collection_

Model ke shikhate hobe “intrusion kemon lage”.

_Data lagbe:_

- **Restricted area er CCTV footage**: normal time, working hour, off hour

- **Intrusion er sample** (_Abnormal Events_): These are activities your model should detect as suspicious or dangerous.

> Like

| Category                        | Sample Scenario                        |
| ------------------------------- | -------------------------------------- |
| **After-hours intrusion**       | Person entering shop at midnight       |
| **Unauthorized entry**          | Someone climbing over gate/window      |
| **Burglary**                    | Thief breaking lock or glass           |
| **Shoplifting**                 | Person hiding products in bag          |
| **Loitering**                   | Standing near entrance for long time   |
| **Weapon detection**            | Person carrying gun/knife              |
| **Fire/Arson**                  | Flames or smoke inside shop            |
| **Vandalism**                   | Damaging CCTV or property              |
| **Fighting**                    | Physical violence between people       |
| **Forced access**               | Door being kicked/pushed open          |
| **Restricted-area access**      | Person entering staff-only zone        |
| **Suspicious movement**         | Crawling, sneaking, hiding face        |
| **After-hours movement**        | Motion detected when store closed      |
| **Running during closed hours** | Fast movement at night                 |
| **Vehicle intrusion**           | Car entering restricted zone           |
| **Object theft**                | Taking cash register/item and escaping |

- **Non-Intrusion** (_Normal Events_): These activities should be labeled as normal behavior.

> Like

| Category                    | Sample Scenario                  |
| --------------------------- | -------------------------------- |
| **Normal shopping**         | Customer browsing products       |
| **Cashier activity**        | Staff working at counter         |
| **Cleaning**                | Employee mopping floor           |
| **Walking**                 | Person normally entering/exiting |
| **Restocking**              | Staff arranging shelves          |
| **Sitting**                 | Customer waiting normally        |
| **Talking**                 | People having conversation       |
| **Queueing**                | Customers standing in line       |
| **Opening/closing shop**    | Authorized staff entering        |
| **Delivery activity**       | Delivery person dropping package |
| **Normal vehicle movement** | Parking properly                 |
| **Cart movement**           | Customer pushing trolley         |
| **Pet movement**            | Cat/dog passing outside          |
| **Lighting changes**        | Headlights or sunlight changes   |
| **Fan/shadow motion**       | Environmental movement           |
| **Authorized night staff**  | Security guard patrol            |

### Simple Binary Label Example

| Label | Meaning                |
| ----- | ---------------------- |
| `0`   | Non-Intrusion / Normal |
| `1`   | Intrusion / Suspicious |

_Tip:_ Public dataset use koro age.  
`MOT20, PETS, VIRAT, MEVA` = person detection er jonno valo.  
Na pele nijer phone diye 2 din record koro.

#### _Step 2: Object Detection - YOLOv8_

Ekhane tomake bolte hobe “frame e manush ache kina”.

_Keno **YOLOv8**:_  
Real-time **30 FPS** e chole. CCTV te lagbe na.

```py
from ultralytics import YOLO
model = YOLO('yolov8n.pt') # n=nano, fast
results = model.predict('cctv.mp4', conf=0.5)
```

Output: `person 0.92 [x1,y1,x2,y2]`

#### _Step 3: Object Tracking - DeepSORT_

Detection shudhu 1 frame er jonno. Tracking lagbe bujhte “eta same person kina 10 sec dhore”.

- **Logic:** Frame 1 e person ID 1, Frame 2 e o same person hole ID 1 thakbe.
- **Library:** `deep-sort-realtime`.

Ete tumi bujhba “ke kotha diye kothay jacche”.

#### _Step 4: Intrusion Logic_

Ekhane rule + DL mix hobe.

> _Rule-based:_

- Define koro “Restricted Zone” = image er ekta polygon area
- Jodi person er bounding box er center oi zone er moddhe 2 sec thake = Intrusion

> _DL-based:_

- Choto CNN/LSTM train koro jeta sequence dekhe bolbe “suspicious movement kina”.
- Example: Raat e fence topke dhukle pattern alada hoy.

#### _Step 5: Alert System_

Intrusion detect hole:

- Telegram/Email alert pathao screenshot soho
- Sound alarm bajao
- Video clip save koro evidence hisebe
- Dashboard e red mark koro

# _3. Tomar Shikhar Order_

Ekhon theke **3 week** er plan:

### _Week 1: Foundation_

- OpenCV: video read, draw rectangle, crop
- YOLOv8: pre-trained model diye person detect kora
- Goal: CCTV video te sob person er upor box bosate paro

### _Week 2: Tracking + Zone_

- DeepSORT add koro
- Mouse diye restricted zone draw koro
- Jodi person zone e dhuke, console e “INTRUSION” print koro

### _Week 3: Smart Logic + Deploy_

- False alarm komao: tree shaking, light change ignore koro
- Telegram bot add koro
- Jetson Nano/Raspberry Pi te chalano sikho real CCTV er jonno

# _4. Common Problem + Solution_

| Problem                                  | Keno hoy                         | Solution                                   |
| ---------------------------------------- | -------------------------------- | ------------------------------------------ |
| **False alarm rate beshi**               | Chaya, alo change ke manush vabe | Background subtraction + tracking use koro |
| **Raat e detect hoy na**                 | Low light                        | YOLOv8x use koro, IR camera use koro       |
| **CPU te slow**                          | Heavy model                      | YOLOv8n use koro, frame skip koro          |
| **2 jon overlap hole tracking gule jay** | ID switch                        | DeepSORT er `max_age` barai dao            |
